# Artifact notes

This release is intentionally publication-facing. It retains compact raw replication records, frozen summaries, manifests, controller labels, protocols, and integrity hashes. It excludes model weights, source images, large intermediate grids, cached environments, obsolete experiments, draft paper files, handoffs, and exploratory figures.

Some analysis utilities require the full private research archive to recompute historical Phase A/Phase B outputs. The frozen public summaries remain auditable through their CSV/JSON content and integrity manifests. The 210×3 replication can be re-audited from the compact raw records included here.

The private sample-to-condition mapping for the blinded qualitative study is deliberately withheld from the public tree while annotation is pending. It remains in the secured research archive.
